# Wiki

This directory is the project's knowledge base. It is not user documentation:
user-facing docs live in [docs/](docs/).

## Conventions

- One page per session that produced knowledge worth keeping: an investigation,
  a debugging chase, a review, or a set of changes.
- Pages live in `pages/` and are named `YYYY-MM-DD-short-slug.md`.
- Add every new page to [INDEX.md](INDEX.md), newest first, and to a topic
  cluster when one fits.
- Use [TEMPLATE.md](TEMPLATE.md) as the starting point.
- Link to source files and commits rather than pasting them.
- [QUESTIONS.md](QUESTIONS.md) records open questions and their answers, so
  they are not re-litigated later.

## Docs

`docs/` owns what users read:

- [INSTALL.md](docs/INSTALL.md) — install options.
- [MORE.md](docs/MORE.md) — shortcuts, the state format, supported formats.
